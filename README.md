### ALGO-000229: Mansour’s conjecture
- **Subfield:** Pseudorandomness, derandomization, and Boolean analysis
- **Open:** Prove that an \(s\)-term DNF has nearly all Fourier mass on a set of polynomially many coefficients for every fixed approximation error.
- **Status:** Proposed in the early 1990s. Random-DNF and restricted-parameter cases are known; the general concentration statement remains unresolved.
- **Type:** theory
- **Why:** Would substantially improve understanding of the spectral and learning complexity of DNF.
- **Key works:** Mansour’s original Fourier-learning work; *Mansour’s Conjecture Is True for Random DNF Formulas* (2010), ECCC TR10-023; *Sharper Bounds on Fourier Concentration of DNFs*, arXiv:2109.04525.
- **Related:** Machine learning theory—efficient DNF learning.
